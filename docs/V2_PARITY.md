# مطابقة وظائف v2 مع v3

القاعدة: لا تُحذف وظيفة من v2 دون بديل في v3. الجدول مبني على قراءة كل ملفات v2
(`reference/v2/`). عمود «الحالة» يُحدَّث مع التنفيذ: ⬜ لم يبدأ · 🟨 قيد التنفيذ · ✅ منجز ومُختبر.

## 9. اختبارات v2

اختبارات v2 السبعة والعشرون (التحقق، الفلترة، الإحصاءات، CSV، المستودع، المواقع، اختيار الخريطة،
الأشخاص، الصور، القوائم السريعة) يقابلها في v3 اختبارات Vitest للوحدات المماثلة، مع تغيير
متعمَّد واحد: اختبار «إعادة استخدام الاسم نفسه دون تكرار» يُستبدل باختبار «لا دمج تلقائي».
