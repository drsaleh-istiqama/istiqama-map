# Istiqama Projects Map — v3

Centralised, offline-first system for surveying and following up the mosques and Qur'an
schools of the Istiqama association across East Africa.

- Spec: [`docs/BRIEF.md`](docs/BRIEF.md) · Architecture: [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md)
- Progress: [`PROGRESS.md`](PROGRESS.md) · Owner decisions: [`docs/OWNER_DECISIONS.md`](docs/OWNER_DECISIONS.md)

## Run locally

```bash
npm install
npm run stack:setup
npm run stack:start
npm run db:reset
npm run dev
```

See [`CLAUDE.md`](CLAUDE.md) for test commands and working rules.
