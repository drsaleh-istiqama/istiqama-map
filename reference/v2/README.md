# خارطة مشاريع الاستقامة — النسخة التشغيلية الثانية

تطبيق ويب تقدمي (PWA) عربي لحصر المساجد ومدارس القرآن وإظهارها على خريطة.

## التشغيل المحلي

```bash
cd istiqama-map-app-v2
python3 -m http.server 8765
```

ثم افتح: `http://localhost:8765`

> يلزم تشغيله عبر خادم محلي أو HTTPS حتى تعمل خصائص PWA والموقع الجغرافي بصورة صحيحة.

## الوظائف المنجزة

- خريطة OpenStreetMap حقيقية عبر Leaflet.
- إضافة وتعديل وحذف المشاريع.
- التقاط GPS أو اختيار الموقع على الخريطة عبر مسار واضح: تحديد النقطة، اعتمادها والعودة إلى الاستمارة، أو الرجوع دون تغيير.
- قوائم مترابطة للدولة ثم المحافظة/الإقليم ثم المدينة/القرية، مع إدخال يدوي للمواقع غير المدرجة.
- دليل أشخاص محلي يحفظ الوكيل والمعلم والمدير والإمام والإداري، ويسترجع بيانات الشخص تلقائيًا عند إسناده إلى مشروع آخر.
- نمط إدخال سريع يستهدف إكمال السجل الأساسي خلال 5 دقائق؛ الحقول الإضافية مطوية ويمكن استكمالها لاحقًا.
- التحديات والأنشطة والقضايا وسبل المعيشة خيارات متعددة محددة، ولا تظهر الكتابة الحرة إلا عند اختيار «أخرى».
- أنواع: مسجد، مدرسة قرآن، مسجد ومدرسة.
- حالات: يعمل، يحتاج صيانة، قيد الإنشاء، متوقف.
- اختيار عدة صور من الجهاز دفعة واحدة وضغطها تلقائيًا.
- زر مستقل لكاميرا الهاتف: معاينة، اعتماد، إعادة التقاط أو إلغاء دون فقد الاستمارة.
- تصنيف كل صورة: واجهة المسجد، داخله، واجهة المدرسة، داخلها، أرض، مرافق، صيانة أو أخرى.
- حذف الصورة أو إعادة التقاطها؛ تبقى القديمة عند إلغاء إعادة الالتقاط.
- الصور القديمة ذات الحقل photo تظهر دون فقدان؛ الصور الجديدة في photos.
- الحفظ النهائي للصور مع زر «حفظ المشروع»؛ لا يوجد رفع مركزي في هذه النسخة.
- حماية إلغاء منتقي الصور من إغلاق الاستمارة، ومنع الحفظ أثناء ضغط الصور.
- إصدار الصور: 2.5.0؛ الكاميرا الفعلية تحتاج اختبارًا على هاتف المستخدم، واختبار المتصفح الآلي يستخدم ملفات صور بدل العتاد.
- بحث وفلاتر حسب المنطقة والنوع والحالة.
- بطاقة تفاصيل واتجاهات Google Maps.
- إحصاءات حسب النوع والمنطقة والسعة والصيانة.
- تصدير CSV ونسخة JSON احتياطية، واستيراد JSON.
- حفظ محلي على الجهاز عبر localStorage.
- Service Worker والعمل دون اتصال للواجهة والبيانات؛ مربعات الخريطة المتصفحة سابقًا فقط تتاح دون اتصال.
- تصميم RTL متجاوب مع الهاتف والكمبيوتر.

## حدود هذه النسخة

هذه نسخة تشغيلية محلية وليست بعدُ نظامًا مركزيًا متعدد المستخدمين. قبل الإطلاق المؤسسي يلزم:

1. قاعدة بيانات مركزية Postgres/PostGIS.
2. تسجيل دخول وصلاحيات حقيقية.
3. رفع الصور إلى تخزين سحابي بدل localStorage.
4. سجل تدقيق واعتماد البيانات.
5. نسخ احتياطي مركزي واستضافة HTTPS.
6. قوائم جغرافية رسمية معتمدة للدول والمناطق.
